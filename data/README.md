# Данные проекта (Diamonds Dataset)

⚠️ **Внимание:** Исходный файл с данными `diamonds.csv` добавлен в `.gitignore` и не загружается в репозиторий GitHub из-за ограничений на размер файлов.

## 📥 Как получить данные
Для запуска проекта необходимо поместить файл `diamonds.csv` в эту папку (`data/`). 
* **Источник данных:** Парсинг b2c-платформы jamesallen.com.
* **Период сбора:** Данные актуальны на **01.07.2022**.

---

## 📊 Описание признаков (Data Dictionary)

Датасет содержит детальные характеристики обработанных алмазов (бриллиантов) со следующими полями:

| Название столбца | Тип данных | Описание | Пример значения |
| :--- | :---: | :--- | :--- |
| `id` | Int | Уникальный идентификатор записи (номер лота) | *13870838* |
| `fluor` | Object | Наличие флуоресценции (NONE, MED, STG) | *NONE* |
| `symmetry` | Object | Оценка симметрии камня (EX, VG, G) | *EX* |
| `platform` | Object | Торговая площадка | *jamesallen* |
| `shape` | Object | Форма огранки (RD — круглый, PS — груша, OV — овал и др.) | *RD* |
| `color` | Object | Группа цвета (от D — бесцветный до K/J) | *H* |
| `clarity` | Object | Группа чистоты (IF, VVS1, VVS2, VS1, VS2, SI1, SI2, I1) | *SI1* |
| `cut` | Object | Качество огранки (EX, VG, G) | *EX* |
| `polish` | Object | Качество полировки поверхностей | *EX* |
| `date` | Int | Год и месяц фиксации цены (в формате ГГГГММ) | *202206* |
| `price` | Float | Итоговая стоимость бриллианта в USD | *12850.0* |
| `carat` | Float | Вес камня в каратах | *1.55* |
| `price_per_carat`| Float | **Целевая переменная**: Цена за 1 карат (USD) | *8290.32* |
| `x`, `y`, `z` | Float | Геометрические размеры в мм (длина, ширина, высота) | *6.41, 6.45, 62.0* |
| `depth_perc` | Float | Отношение высоты к общему диаметру (%) | *62.5* |
| `y` (в конце) | Float | Дополнительный коэффициент или дублирующий геометрический параметр | *3.97* |

---

## 🔧 Предварительный анализ аномалий
При работе с данными в скриптах очистки учитываются следующие особенности:
1. Поля размеров (`x`, `y`, `z`) содержат нулевые значения, требующие удаления или импутации.
2. Столбец `polish` содержит пропуски (`nan`), которые необходимо обработать.
3. Поле `date` используется для группировки данных по месяцам при расчете коэффициентов инфляции.
