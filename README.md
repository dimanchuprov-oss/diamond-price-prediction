# Прогнозирование стоимости бриллиантов (Регрессия)

Репозиторий содержит учебный проект по исследованию данных и построению моделей машинного обучения для прогнозирования стоимости бриллиантов (`price_per_carat`). 

Проект выполнен в контексте бизнес-задачи: оценки изменения рынка в связи с отменой НДС на бриллианты с 1 октября и создания актуальной модели ценообразования.

## 🎯 Цель проекта
Разработать и применить пайплайн предобработки данных с учетом инфляционных процессов, а также построить и сравнить несколько моделей регрессии для точного предсказания цен.

## 📊 Исходные данные
В качестве основы используется датасет, содержащий характеристики бриллиантов и цены на них с сайта **jamesallen** (b2c-платформа) по состоянию на **01.07.2022**.

Основные признаки:
* `carat` — вес в каратах.
* `cut`, `color`, `clarity` — качественные характеристики огранки, цвета и чистоты.
* `depth`, `table`, `x`, `y`, `z` — геометрические параметры камня.
* `price_per_carat` — целевая переменная (цена за карат).

## 🛠️ Этапы реализации проекта

### Задание 1: Очистка данных и учет инфляции
1. **Поиск дубликатов и аномалий:** Выявление повторных продаж в течение месяца, очистка данных по каждому конкретному самоцвету, обработка аномальных скачков цен и нулевых параметров размеров.
2. **Расчет инфляции:** Группировка цен по категориям, расчет коэффициентов инфляции для каждой группы и корректировка стоимости камней на последний доступный месяц.

### Задание 2: Моделирование и пайплайны
1. **Валидация:** Разделение данных на обучающую (`train`) и валидационную (`valid`) выборки.
2. **Предобработка:** Проектирование кастомного класса/функции кодирования признаков (сравнение `LabelEncoder` и `TargetEncoder` / `OneHotEncoder`), заполнение пропусков (`fillna`) и масштабирование (`StandardScaler`).
3. **Обучение моделей:**
   * Линейная регрессия (Baseline)
   * Метод k-ближайших соседей (KNN)
   * Деревья решений (Decision Trees)
   * Ансамблевые методы (Random Forest / Бустинг)
